# Метаданные библиотеки

Карточка сохраняет стабильный ID `minecraft-26-2`. Отображаемое имя и путь установки `relativePath` совпадают с `Minecraft Java Edition`.

`emi` указывает на [EMI Unofficial Port (Unstable)](https://www.curseforge.com/minecraft/mc-mods/emi-unofficial-port-unstable). Поставляется JAR автора этого порта, поэтому страница исходного EMI другого проекта не подставляется вместо него. Автор link-fgfgui, точные CurseForge files 8616659 → 9242955 и старый/новый SHA-256 проверены при подготовке обновления; см. [протокол](../tools/UPGRADE-26.3.md). Новый файл для Minecraft 26.3 имеет канал Alpha, как и прежний порт для 26.2.

В библиотеке указаны четыре самостоятельных мода: EMI, Iris, Sodium и Pause Menu Actions (`lanmc_pause_actions`). Последний существует только внутри этой сборки: его официальная страница с описанием, исходниками и поставкой находится в репозитории сборки, отдельного проекта CurseForge/Modrinth нет. Ссылка не подменяется одноимённым чужим модом. e4steam устанавливается общим лаунчером отдельно и не дублируется в репозитории. Исторические EMI и отменённый `lanmc_world_menu` из `legacyFiles` не входят в активную библиотеку или загрузки.

`tools/pack_library.py` читает имена и версии из реальных JAR, требует проверенные HTTPS-страницы, собирает детерминированный `library-<sha256>.zip` и записывает `websiteUrl`. Предыдущие наблюдения состава Iris/Sodium находятся отдельно в `tools/shader-support-runtime.json`; они не подменяют проверку нового компонента меню. Новое меню проверяется настоящим Mixin и нативными виджетами без нового игрового прогона.

Pause Menu Actions сам реализует клиентское меню и уведомляет поиск Steam-миров, поэтому не относится к библиотекам/API. `libraryIds` пуст: все четыре мода входят в основной список и его счётчик. Вспомогательных библиотек в карточке нет; существующий лаунчер скрывает пустую секцию по `HasLibraries`. Версия и SHA256 Pause Menu Actions 1.0.1 этим изменением не меняются.
