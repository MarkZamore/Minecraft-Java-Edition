# Метаданные библиотеки

Карточка сохраняет стабильный ID `minecraft-26-2`. Отображаемое имя и путь установки `relativePath` совпадают с `Minecraft Java Edition`.

В библиотеке указаны три самостоятельных мода: Iris, Sodium и Pause Menu Actions (`lanmc_pause_actions`). Последний существует только внутри этой сборки: его официальная страница с описанием, исходниками и поставкой находится в репозитории сборки, отдельного проекта CurseForge/Modrinth нет. Ссылка не подменяется одноимённым чужим модом. e4steam устанавливается общим лаунчером отдельно и не дублируется в репозитории. Исторические EMI и отменённый `lanmc_world_menu` из `legacyFiles` не входят в активную библиотеку или загрузки.

`tools/pack_library.py` читает имена и версии из реальных JAR, требует проверенные HTTPS-страницы, собирает детерминированный `library-<sha256>.zip` и записывает `websiteUrl`. Предыдущие наблюдения состава Iris/Sodium находятся отдельно в `tools/shader-support-runtime.json`; они не подменяют проверку нового компонента меню. Новое меню проверяется настоящим Mixin и нативными виджетами без нового игрового прогона.

Pause Menu Actions сам реализует клиентское меню и уведомляет поиск Steam-миров, поэтому не относится к библиотекам/API. `libraryIds` пуст: все три мода входят в основной список и его счётчик. Вспомогательных библиотек в карточке нет; существующий лаунчер скрывает пустую секцию по `HasLibraries`.
